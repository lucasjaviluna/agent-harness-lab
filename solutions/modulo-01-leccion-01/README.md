# Solución al ejercicio de la Lección 1

Ejercicio: implementar `agent-lab run-file <ruta>` sin duplicar la lógica de ejecución.

Copia `src/cli.ts` sobre el original, ejecuta `npm test`, y opcionalmente
copia `tests/run-file.test.mjs` a `tests/` para verificar los nuevos casos.

El fichero de solución está completo para que puedas compararlo con tu implementación.
