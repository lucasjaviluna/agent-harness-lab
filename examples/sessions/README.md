# Archivo sintético de sesión

`session-tree.synthetic.jsonl` muestra la idea básica de un encabezado y un árbol con `id`/`parentId`.
**No es una sesión producida por Pi y puede omitir campos requeridos**; no debe pasarse a `--session` para continuar conversaciones.
Usalo para visualizar cómo dos entradas diferentes pueden apuntar a un mismo antecesor.
El formato real está documentado en https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/session-format.md
